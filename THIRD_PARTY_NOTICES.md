Source: [BarryBarrywu/codex-zectrix-dashboard](https://github.com/BarryBarrywu/codex-zectrix-dashboard)

License: MIT

The following foundations in Codex Phone Dashboard are adapted from the upstream project:

- Codex app-server initialization, quota requests, task pagination, and repeated-cursor protection.
- Read-only rollout discovery and lifecycle-event normalization.
- Privacy-first handling of quota and task lifecycle metadata.

Codex Phone Dashboard substantially changes and extends that foundation with a phone-browser product, a Node.js Windows/macOS local-LAN service, pairing and browser sessions, bilingual responsive UI, quota themes, task interactions, optional SSH host aggregation, cross-platform startup/install tooling, privacy-minimized browser snapshots, automated tests, Skill packaging, and public screenshot generation.
